# Freshsales Name Checker

Легке розширення Manifest V3 для Chrome та Edge. Працює лише на заданому домені `bbq1-465157612863820669.myfreshworks.com/crm/messaging/`.

## Встановлення

1. Завантажте й розпакуйте архів `name-checker-extension.zip`.
2. Відкрийте `chrome://extensions` (Edge: `edge://extensions`).
3. Увімкніть «Режим розробника» → «Завантажити розпаковане».
4. Виберіть папку `extension`, у якій лежить `manifest.json`.
5. Перезавантажте вкладку Freshsales, відкрийте Contact info та редактор листа.

Панель показує ім’я з картки, збіг або можливу помилку. Наприклад, для картки `Oscar email@example.com Clarke`: `Hello Oscar,` — збіг, `Hello Oskar,` — попередження. Кнопка «Перевірити зараз» запускає перевірку вручну. Розширення не змінює лист і не блокує Send.

## Межі перевірки

- Порівнюється перший рядок із привітанням Hello / Hi / Hey / Dear / Good morning / afternoon / evening, Вітаю / Привіт / Шановний / Шановна. У темі також підтримується формат `Oscar, текст теми`.
- Email у полі імені ігнорується. Регістр не враховується; різні імена, транслітерації та пестливі форми автоматично не прирівнюються. Український кличний відмінок може дати попередження.
- Не шукає всі імена у тексті, цитатах та підписах. Відсутність розпізнаного звертання не означає, що весь лист перевірено.
- Ім’я береться з видимої картки Contact info. Без неї перевірка недоступна. Картка сама має містити правильні дані.
- Підтримуються MediumEditor, Froala та доступні iframe Froala. Селектори взято зі збереженої сторінки. Новий лист показано лише на скриншоті: селектори його теми потрібно підтвердити на живому сайті. Закриті shadow DOM і сторонні iframe не підтримуються.
- Для внутрішніх нотаток може також показуватися панель; розширення нічого не надсилає.

## Продуктивність і приватність

Без бібліотек, сервера, API, телеметрії, сховища та фонових процесів. Перевірка локальна, після подій вводу/змін DOM із затримкою 250 мс, без постійного таймера. Аналізується лише поточний редактор та ім’я з картки; історія переписки не сканується. На дуже активній сторінці загальний MutationObserver може спричиняти додаткові перевірки. Числові гарантії CPU/RAM не вимірювалися.

## Розробка та перевірка

Збірка та встановлення залежностей не потрібні. Використовуйте наявний checkout; новий worktree не потрібний.

```sh
node tests/checker.test.cjs
node --check extension/content.js
```

На живому сайті перевірте: правильне/неправильне звертання, тему нового листа, відповідь в існуючій переписці, зміну клієнта без перезавантаження та закриту картку. Автоматичні тести не підтверджують роботу всередині авторизованого Freshsales.
